I. What PCVH Is

PCVH (Proof-Carrying Verification Harness) is a formal verification and differential-conformance gate for shipping software. Unit tests and fuzzers sample finitely many inputs; catastrophic bugs in financial ledgers, consensus thresholds, compiler passes, zero-knowledge circuits, and agent sandboxes hide in boundary arithmetic, multi-step state aliasing, and rounding corners that random inputs rarely hit.

Traditionally, closing that gap with interactive theorem proving required human specialists to write and maintain thousands of lines of brittle proof scripts. PCVH inverts the workflow: an engineer (or auditor) defines and pins only a ~50-line domain specification in Lean 4, autonomous proof search synthesizes the tactic proofs, and a differential trace bridge checks the shipping Rust, TypeScript, Solidity, or Python implementation bit-for-bit against that exact specification on every pull request.

1 · Scaffold & Pin (pcvh init / pcvh pin) Generates a paired Lean 4 specification (Statement.lean + Challenge.lean), production target skeleton (Rust, TypeScript, Solidity/Foundry, or Python), and SHA-256 lockfile (spec.lock.json).
2 · Refute Fast (pcvh falsify) Before spending compute on proof search, Stage-2 bounded evaluation runs randomized and boundary witnesses in Lean 4 to refute defective specifications or false invariants in ~2 seconds with concrete counterexamples.
3 · Synthesize & Maintain (pcvh prove / diff-reprove) Decomposes lemmas along the call graph, applies symbolic tiers, live Lean 4 LSP goal-state tree search, and optional LLMs, and caches unaffected lemma proofs across pull requests.
4 · Gate & Attest (pcvh verify / pcvh studio) Rebuilds inside an isolated sandbox, verifies kernel definitional equality + dual-kernel replay + 500–1,000 live target traces, and emits an Ed25519 DSSE-signed proof-attestation.json.

II. Palomar Zero-Trust Architecture

Automated provers and coding agents optimize aggressively for passing checks—including weakening definitions, introducing sound-looking axioms, or proving vacuous implications with unreachable hypotheses. PCVH isolates what a human reviewer must read (~50 lines of domain types and theorem signatures in Zone I) from untrusted proof synthesis and production optimizations (Zone II), enforcing equivalence inside an ephemeral clean-room comparator (Zone III).

export function evalToolCall(pol: Policy, st: GuardState, call: ToolCall): [DecisionCode, GuardState] {
  if (st.halted) return [DecisionCode.DeniedHalted, st];
  if (call.tripKillSwitch) return [DecisionCode.DeniedHalted, { ...st, halted: true }];
  if (call.isPathTraversal || call.scopeId !== pol.allowedScopeId) return [DecisionCode.DeniedScope, st];
  if (call.isDestructive && !call.hasHumanApproval) return [DecisionCode.DeniedApproval, st];
  if (pol.maxCalls <= st.callCount) return [DecisionCode.DeniedRateLimit, st];
  if (pol.maxBudgetCents < st.spentCents + call.costCents) return [DecisionCode.DeniedBudget, st];
  return [DecisionCode.Allowed, { spentCents: st.spentCents + call.costCents, callCount: st.callCount + 1, halted: false }];
}

pub fn match_bid_ask(bid: Order, ask: Order, cur_seq: u64) -> MatchOutcome {
    if ask.price <= bid.price && bid.qty > 0 && ask.qty > 0 {
        let fill = bid.qty.min(ask.qty);

            fill_qty: fill,
            exec_price: ask.price,
            rem_bid_qty: bid.qty - fill,

class WireGuardReplayWindow:
    def accept_packet(self, seq: int) -> bool:
        if not self.initialized:
            self.initialized, self.highest, self.bitmap = True, seq, 1
            return True
        if seq > self.highest:
            delta = seq - self.highest
            self.bitmap = 1 if delta >= 64 else (((self.bitmap << delta) & MASK_64) | 1)
            self.highest = seq
            return True
        offset = self.highest - seq
        if offset >= 64 or ((self.bitmap >> offset) & 1) == 1:
            return False
        self.bitmap |= (1 << offset)
        return True
